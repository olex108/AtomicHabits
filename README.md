# AtomicHabits

Сервис для создания и отслеживания полезных привычек с интеграцией в Telegram и автоматическими напоминаниями. Реализован на базе методики «Атомные привычки» Джеймса Клира.

## 🛠 Технологии

- Python 3.13+
- Django 5.2.7+ & Django REST Framework (API)
- PostgreSQL (База данных)
- Redis (Брокер сообщений)
- Celery & Celery Beat (Отложенные задачи и расписание)

## 🚀 Функционал

#### Авторизация: Регистрация и вход по номеру телефона (JWT-токены).
#### Привычки:
- CRUD для личных привычек.
- Просмотр списка публичных привычек всех пользователей.
#### Валидация: время выполнения (до 120 сек), периодичность (не реже раза в 7 дней).
#### Логика «приятных» привычек и вознаграждений.
#### Уведомления:
#### Автоматическое создание расписания при сохранении привычки.
#### Рассылка напоминаний в Telegram-бот.
#### Безопасность: Настроенные CORS-политики и права доступа (IsOwner).

## 🔧 Установка и запуск

1. Клонирование репозитория
```
git clone https://github.com/olex108/AtomicHabits.git
```

2. Настройка окружения

Создайте файл .env в корне проекта и заполните его:

```
SECRET_KEY=your_django_secret_key
NAME=habits_db
USER=postgres
PASSWORD=your_password
HOST=localhost
PORT=5432

BOT_API_KEY=your_telegram_bot_token
```

4. Установка зависимостей и миграции

```
poetry install
python manage.py migrate
```

5. Запуск сервисов (в разных терминалах)

- Django сервер: python manage.py runserver
- Telegram Бот: python manage.py run_bot
- Celery Worker: celery -A config worker -l info -P eventlet
- Celery Beat: celery -A config beat -l info

### 🤖 Как привязать Telegram

- Найдите своего бота в Telegram и отправьте команду /start.
- Нажмите кнопку "Отправить контакт".
- Бот автоматически свяжет ваш chat_id с аккаунтом в базе по номеру телефона.
